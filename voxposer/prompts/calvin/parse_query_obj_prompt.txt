# ----------------------------------------------------------------------------
# Which block an instruction means. These queries quote a whole instruction:
#     the block meant in: <instruction>
# Find the words that say which block, and return that block.
# blocks(where) lists the blocks lying in one place: blocks('table'),
# blocks('drawer'), blocks('cabinet') (the sliding cabinet), blocks('gripper');
# blocks() lists every block, wherever it is. position[0] grows to the RIGHT,
# position[1] grows toward the BACK (the front edge of the table, nearest the
# robot, has the smallest value), position[2] grows UP. Reading the instruction:
#   which blocks   Unless a place is named, the blocks on the table. A block
#                  said to be in the drawer or the cabinet comes from that
#                  list; the whole workspace / scene: every block. The drawer
#                  (also called a compartment) is the only thing that is ever
#                  open, shut or pulled out, so an unnamed thing in one of
#                  those states is the drawer; the cabinet is never called
#                  open or shut.
#   the cabinet    Its sliding door stands where the 'slider_handle' is, in
#                  front of one half. A block behind the door is the cabinet
#                  block nearest the door along position[0]; a block in the
#                  uncovered half is the one farthest from it.
#   edges          Nearest the front edge of a place = smallest position[1]
#                  there; the back edge = largest position[1]; the left edge
#                  = smallest position[0]; the right edge = largest.
#   held           The held block is blocks('gripper')[0]. If the instruction
#                  speaks of a held block but that list is empty, nothing is
#                  held: return the block that suits the action instead, as
#                  when there is no description. Never return None.
#   size           b.obb_size is a block's (width, depth, height). A size word
#                  (largest, smallest) decides the block; a location said
#                  along with it only describes that block.
#   the camera     looks at the table from far away at the front right, so
#                  nearer the camera means further to the front right.
#   no description ("the block", "a block", "the object"): the block that suits
#                  the action, as in the last four examples below.
# Take the candidates, then pick one with min / max. Assign ret_val once, on the
# last line.
# ----------------------------------------------------------------------------
objects = ['red block', 'blue block', 'pink block', 'table']
# Query: the block meant in: turn the block at the far left of the table clockwise.
ret_val = min(blocks('table'), key=lambda b: b.position[0])

objects = ['red block', 'blue block', 'pink block', 'table']

# No place is named: the blocks on the table. Farthest from the robot = farthest back.
ret_val = max(blocks('table'), key=lambda b: b.position[1])

objects = ['red block', 'blue block', 'pink block', 'table']
# Query: the block to pick up in: put one block on top of another.
# No description. A block picked up to be stacked: the block on the table
# closest to the gripper.
gripper = detect('gripper')
ret_val = min(blocks('table'), key=lambda b: np.linalg.norm(np.array(b.position) - np.array(gripper.position)))

objects = ['red block', 'blue block', 'pink block', 'table']
# Query: the block to stack onto in: put one block on top of another.
# The block being stacked is the held one or, with nothing held, the one that
# will be picked up. The block to stack onto is the other table block nearest it.
gripper = detect('gripper')
held = blocks('gripper')
moving = held[0] if held else min(blocks('table'), key=lambda b: np.linalg.norm(np.array(b.position) - np.array(gripper.position)))
others = [b for b in blocks('table') if b.name != moving.name]
ret_val = min(others, key=lambda b: np.linalg.norm(np.array(b.position) - np.array(moving.position)))
